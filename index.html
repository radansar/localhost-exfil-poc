Requires server.py running locally. Page must be served from a public HTTPS origin.

Channel 1 — <img> via HTTP (Safari only)

Safari loads HTTP images from localhost even from an HTTPS page (passive mixed-content). Identifier travels in the URL query string.

Channel 2 — TLS SNI (Safari + Chrome)

Identifier encoded as hex in the SNI hostname. Server reads it from the raw TLS ClientHello before any cert check. No certificate required.

Channel 3 — HTTPS fetch (Safari · requires trusted cert)

Full bidirectional HTTP over TLS. Safari places no gate on HTTPS-to-localhost from a public HTTPS page.
Domain must resolve to 127.0.0.1 with a browser-trusted certificate.
Testing: use mkcert (mkcert -install + generate cert for localhost).
Production: any domain with A record → 127.0.0.1 and a valid Let's Encrypt cert.
